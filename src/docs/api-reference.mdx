# API reference


Every endpoint in the public PayGrid API, with parameters, request bodies,
responses, and errors. Endpoints are grouped by resource; each resource has its
own page.

## Resources

| Resource | Description |
| --- | --- |
| [Customers](/docs/customers) | Create, list, fetch, and update customers. |
| [Virtual accounts](/docs/virtual-accounts) | Provision and inspect dedicated virtual accounts. |
| [Invoices](/docs/invoices) | Create, send, cancel, and track invoices. |
| [Transactions](/docs/transactions) | List and inspect reconciled transactions. |
| [Business](/docs/business) | Fetch the business profile bound to your API key. |
| [Webhooks](/docs/webhooks) | Manage outgoing webhook subscriptions. |

## Conventions

- **Auth** — all endpoints require `Authorization: Bearer <api-key>`. A key with
  empty scopes bypasses the scope check. See [Authentication](/docs/authentication).
- **Envelope** — successful responses wrap data in
  `{ success: true, data: ... }`; failures return
  `{ success: false, error: string }`.
- **Pagination** — list endpoints are cursor-paginated and return
  `meta.cursor`; the first page omits it.
- **IDs** — resources are addressed by `:id` in the path.
