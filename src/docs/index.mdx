# PayGrid API

PayGrid is a programmable accounts receivable platform. It gives businesses
Dedicated Virtual Accounts (DVAs) so inbound bank transfers can be automatically
matched to customers and invoices.

The public REST API (`/api/v1`) is driven by a single, customer-managed API key
that can manage customers, virtual accounts, invoices, transactions, the
business profile, and outgoing webhook subscriptions. Every public endpoint
requires a `Bearer` API key and grants or denies access by OAuth-style scopes.

## Key concepts

- **Customers** — the entities you bill. PayGrid upserts customers by email and
  tracks them across virtual accounts, invoices, and transactions.
- **Virtual accounts (DVAs)** — dedicated account numbers your customers pay
  into. Inbound transfers are automatically reconciled to customers and
  invoices.
- **Invoices** — bills issued to customers. Each created invoice comes with a
  generated `paymentUrl` you can share.
- **Transactions** — reconciled payments and debits, each carrying a
  reconciliation status (`matched`, `underpaid`, `overpaid`, `duplicate`,
  `needs_review`, or `pending`).
- **Webhooks** — outgoing event notifications your backend can subscribe to,
  with a one-time `signingSecret` returned at creation.

| Resource | Description |
| --- | --- |
